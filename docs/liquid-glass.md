# Baha Plus 液态玻璃设计语言

这份文档记录当前 Flutter 界面采用的视觉语言，供新增页面和调整现有界面时参考。Android 和 iOS 共用同一套页面、主题和玻璃组件；平台渲染能力可能影响实际效果。

## 设计原则

- **内容优先**：封面、海报、简介、片单和设置分组保持清晰、实在的内容表面，让图片和文字承担主要视觉层级。
- **玻璃承载操作**：把折射、透明和高光集中用于导航、浮动操作和播放控制，避免把每张内容卡片都做成玻璃。
- **保持层次**：大标题与主封面建立页面焦点；玻璃覆盖在内容上方，不依靠大量副标题或装饰区分层级。
- **保证可读性**：根据背景选择背衬、渐变和文字颜色。避免玻璃叠玻璃；封面上的操作单独采样，确保文字和边缘高光清楚。
- **尊重系统与用户设置**：适配浅色、深色、系统外观、简繁中文、大字体与减少动画设置。

## 基础样式

| 项目 | 当前实现 |
| --- | --- |
| 玻璃组件 | `liquid_glass_widgets: 1.16.1`；启动时初始化并包装应用，使用 `GlassThemeData.ios27()` |
| 渲染质量 | 启用自适应质量；初始和最低质量均为 `GlassQuality.standard`，启用 `frostStep` |
| 品牌及操作色 | `brandBlue`：`#007AFF`，用于选中导航、操作和强调 |
| 页面背景 | 浅色 `#FFFFFF`，深色 `#08080A` |
| 内容表面 | 浅色 `#FFFFFF`，深色 `#1C1C1E`；最低层容器分别为 `#F2F2F7`、`#000000` |
| 字体 | `BahaSans`（Noto Sans TC），文字样式回退到 `BahaSansSC`（Noto Sans SC） |
| 图标 | 以 Cupertino 图标为主；图标操作提供语义标签 |
| 文字层级 | 默认正文 16；导航标题 17 / 600，大标题 34 / 700，标签文字 11；次要文字使用主题前景色的 55% 透明度 |

颜色及文字入口见 `app/lib/main.dart` 和 `app/lib/ui/chrome.dart`。数值是当前实现的参考，不要求所有页面机械套用；优先复用主题和现有组件。

## 组件与布局

| 场景 | 当前做法 |
| --- | --- |
| 页面容器与标题 | `GlassScaffold`、`GlassAppBar`；目录页使用随滚动折叠的 `GlassLargeTitle` |
| 底部导航 | `GlassTabBar.bottom` 浮于内容上方；选中项使用蓝色图标和文字、胶囊指示器，并按明暗模式调整薄背衬 |
| 搜索 | `GlassSearchBar`，目录页使用实色表面和 48 高度 |
| 圆形操作 | `GlassIconButton`，用于头像、关闭、返回、刷新、收藏等；头像入口尺寸为 44 |
| 主要操作 | `GlassButton.custom` 配合圆角形状；封面上的播放操作使用独立玻璃层 |
| 账号面板 | `GlassModalSheet`，接近全屏，顶部圆角 36，展开背景随明暗模式变化 |
| 内容图片 | 封面和海报使用不透明图像、圆角裁切；普通作品缩略图圆角 18，横向列表图圆角 14 |
| 播放控制 | 竖屏在视频下方显示 `GlassContainer`、`GlassSlider` 与 Cupertino 图标；横屏叠放于视频画面，使用较大的按钮和深色背衬 |
| 作品资料 | 详情页与播放页均使用无背景的标签、数值分栏，不添加独立卡片 |
| 评分与留言 | 使用不透明内容表面，并以柔和外部投影和较短的接触阴影加强层次；横向留言预览为上下投影预留空间 |

常用共享组件及媒体玻璃设置位于 `app/lib/ui/chrome.dart`；导航、搜索与面板见 `app/lib/ui/app_root.dart`，封面与详情见 `catalog_pages.dart`、`detail_page.dart`，播放控制见 `player_page.dart`。修改共享样式时，应同时检查这些场景。

封面操作使用的 `mediaGlass` 为透明主体：`glassColor` 为 `0x35FFFFFF`、`backerColor` 为 `0x25FFFFFF`、厚度 12、模糊 5。视频内的控制条和浮动按钮根据需要增加深色背衬，不应直接假定相同参数在所有图片上都清晰。

竖屏播放控制条复用 `mediaGlass` 的透明主体，使用标准渲染质量、厚度 16 和模糊 6。浅色模式采用低透明度的中性灰染色、不加白色背衬，配合柔和的边缘高光与外部投影呈现厚度；深色模式采用低透明度的白色染色和薄深色背衬，避免边缘发白。控制条位于页面背景上，不采样上方的视频画面。

## 交互与背景采样

- 目录页横向切换使用 280 毫秒的位移与淡入；重复点按当前标签可回到顶部。系统要求减少动画时直接切换或跳转。
- 页面内容为底部浮动导航与系统安全区域预留空间；交互控件应保留清晰的点击范围和无障碍语义。
- 官方 WebView 未显示时以 `Offstage` 保留会话，不提交平台视图到画面合成，避免后台网页文字被玻璃导航采样。登录时显示官方页面。
- 播放页在圆角视频区域内显示官方播放表面，Flutter 提供导航、播放控制、选集与作品资料。竖屏控制条固定在视频下方、标题上方；横屏控制条叠放在视频内，正片播放时自动隐藏，触碰视频重新显示。广告和年龄验证等官方界面继续保留。玻璃效果由 Flutter 组件渲染，不能视为调用了 iOS 系统原生的 Liquid Glass 材质。

## 验收清单

设计或组件变更后，根据影响范围检查：

- Android 实机或模拟器中，滚动页面时玻璃背景采样、导航选中状态、按钮按压及图片上的可读性。
- 浅色、深色、简体、繁体、大字体，以及系统减少动画设置；检查文本截断、溢出和安全区域。
- 首页、片库、搜索、账号面板、详情及播放页，包括空状态和已有内容时的表现。
- WebView 登录和播放期间，检查玻璃层、视频画面和官方提示之间的遮挡关系。
- iOS 的玻璃渲染、键盘、WebView 和播放需在 Mac 模拟器或真机单独验收；共用 Flutter 代码本身不代表已经完成平台验证。
