# 用户日志采集

入口是右上角账号面板 → 问题反馈与日志，未登录即可使用。正式版无需 `BAHA_DIAGNOSTICS`、ADB 或开发者模式。用户开始采集后返回应用复现问题，再停止、预览、导出分享；分享失败可复制日志，在页面提供的 GitHub Issues 入口中附上文件或粘贴内容。系统分享取消不表示已向开发者发送。

`AppDiagnostics` 使用应用私有支持目录的 `diagnostics/`，默认不采集。开启标志保存在本机，重新启动时恢复采集，并保留此前的事件，方便闪退后反馈。停止后不再记录新事件；清除会删除两份记录及本机导出文件，保留用户当前的采集开关。发送至其他应用的副本不受清除影响。

事件采用带 UTC 时间的 JSON Lines。单条上限 16 KiB；当前文件达到 512 KiB 时轮转至上一份，总计最多 1 MiB。写入顺序执行，积压上限 128 条，超出计入报告中的丢弃数量；导出与写入／轮转串行，保证读取快照。导出为 UTF-8 `.txt`，含应用版本、构建号、系统版本、Dart 版本、构建模式和当前界面／播放状态。本机保留最近三份导出文件，避免分享扩展读取尚未完成时删除文件。

已接入的事件包括应用启动／前后台、页面操作和超时、主文档网络／HTTP 错误、WebView 进程退出、搜索结果／失败、播放器命令／状态、原生播放器接管和加载失败、系统播放命令回复及每十秒的播放健康指标。健康指标在用户开启采集时也可运行，不启用 Web Inspector。Flutter 和 Dart 未捕获错误只记录异常类型、安全错误代码和堆栈位置，保留原有错误处理器行为。

采集器不截取任意控制台输出，不读取 Cookie、认证存储、页面 HTML、HTTP 正文、弹幕或留言正文。原生媒体异常的 message/details 可能包含签名 URL，因此不记录这些字段；网页健康投影只接收数值、布尔值和已知状态枚举。所有写入与报告元数据还会过滤凭据／账号键、URL、本机 Windows 路径及邮件地址。不要新增原始桥接载荷或媒体源到事件数据。

此功能收集应用可观察事件，不提供系统级 logcat、AVPlayer 原生诊断包或原生崩溃转储。断电、操作系统终止或原生崩溃前尚未落盘的事件可能丢失；重启后仍可导出已落盘的尾部记录。iOS 分享使用按钮的实际全局矩形作为 iPad 弹出面板锚点。

日志专用验证：

```sh
cd app
flutter test test/app_diagnostics_test.dart test/diagnostics_interface_test.dart
```

核心测试覆盖采集开关、重启持久化、脱敏、轮转、输入边界、清除、导出保留数量、真实文件及分享锚点、存储故障与重试、原有异常处理器。界面测试覆盖未登录用户的简繁体采集／停止／分享／预览，以及分享失败后复制与清除确认。系统分享接收端及 iPhone／iPad 原生呈现仍需在相应设备验证。
