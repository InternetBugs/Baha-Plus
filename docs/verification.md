# 本地验收

当前为 Flutter 迁移与播放页重写的开发版本。Android 在本地构建；没有触发 GitHub Actions 或正式发布。

## 已验证

- `flutter analyze --no-pub` 无问题。
- 23 项 Dart 核心及界面测试通过：包括简繁、目录缓存、请求隔离、账号资料及头像校验、切换账号与游客状态清理、首页和账号卡片共用资料、完整播放页、视频内控制区域、选集、全屏返回、后台暂停、登录后的同步导航及首页瀑布流。
- 16 项官网适配器测试通过：包括目录、详情、账号资料、收藏、资料与观看记录身份一致性、播放器状态、广告阶段命令限制、年龄确认保留、错误处理与单一画质选择。
- `npm run resources:check` 验证 140 项双语资源；`npm run typecheck` 通过。
- 本地 x86_64 Android debug APK 编译、安装并运行于 API 35 专用模拟器。
- 实际官网目录与详情读取；搜索输入及清除、语言与外观设置、时间表、片库和账号面板。
- 断网无目录缓存时首页留白；恢复真实缓存后可冷启动显示；失败刷新保留缓存；联网后可刷新。
- 人气片单改为随首页纵向滚动的瀑布流，按内容自然错列并逐项构建，可继续滚动到原横向列表截断数量之外。目录缓存状态行已移除，缓存行为保留。
- 播放页由 Flutter 绘制导航、圆角视频区域、选集、简介及作品资料。
- 视频内玻璃控制条替代原控制栏；没有视频外的独立控制面板。
- 实际广告视频的播放、暂停、静音与时间进度已通过新控件验证。广告期间拖动、快进、倍速与画质命令被阻止。
- 在用户授权测试中点击官方年龄确认后，新会话正常完成广告并进入正片，正片接口返回成功，视频连续播放时间已推进到三分钟以上。
- 真实正片已验证十秒快进/后退、进度拖动、1.5 倍速、静音、官方提供的 360p 画质选择及弹幕显示开关。当前游客会话只提供一个画质档位，多档位及会员画质尚需账号验证。
- 真实正片切入后台后立即暂停；返回前台保持暂停，用户可继续播放。后台加载完成的新文档也保持媒体暂停约束。
- 横屏和竖屏切换保持同一个官方视频文档及当前请求标识。
- 官方账号入口进入巴哈姆特登录页。年龄提示保留在视频区域，测试中的确认点击已获用户明确授权。
- 官方资料读取、账号卡片与首页头像显示，以及覆盖安装并冷启动后的登录会话恢复与资料重读，均已在 Android 模拟器核对。公开记录只保留功能验证结论。

## 尚未完成

- 曾在停留较久的会话中捕获正片接口返回 `1015`，HTTP 状态为 `299`。重新加载并连续完成官方流程后已恢复正片播放。当前证据没有确定该错误的全部触发条件，长时间暂停、跨集及异常网络恢复仍需进一步覆盖。
- 云端收藏增删、观看记录与播放进度，以及多档位和会员画质的完整验收尚未完成，仍需核对官方页面与播放后的记录。
- iOS 工程尚未在 macOS/Xcode 编译或运行。同一份 Dart 布局测试不能代替 iOS 设备验收。
- 正式 Android 签名、iOS 签名及发布流程留待完整功能验收完成。
