# 本地验收

当前为 Flutter 迁移与播放页重写的开发版本。Android 在本地构建；没有触发 GitHub Actions 或正式发布。

## 已验证

- `flutter analyze --no-pub` 无问题。
- 18 项 Dart 核心及界面测试通过：包括简繁、目录缓存、请求隔离、账号数据模型、完整播放页、视频内控制区域、选集及全屏返回。
- 14 项官网适配器测试通过：包括目录、详情、账号、收藏、播放器状态、广告阶段命令限制、年龄确认保留与错误处理。
- `npm run resources:check` 验证 140 项双语资源；`npm run typecheck` 通过。
- 本地 x86_64 Android debug APK 编译、安装并运行于 API 35 专用模拟器。
- 实际官网目录与详情读取；搜索输入及清除、语言与外观设置、时间表、片库和账号面板。
- 断网无目录缓存时首页留白；恢复真实缓存后可冷启动显示；失败刷新保留缓存；联网后可刷新。
- 播放页由 Flutter 绘制导航、圆角视频区域、选集、简介及作品资料。
- 视频内玻璃控制条替代原控制栏；没有视频外的独立控制面板。
- 实际广告视频的播放、暂停、静音与时间进度已通过新控件验证。广告期间拖动、快进、倍速与画质命令被阻止。
- 横屏和竖屏切换保持同一个官方视频文档及当前请求标识。
- 官方账号入口进入巴哈姆特登录页；年龄提示保留在视频区域由用户确认。

## 尚未完成

- 模拟器中一次广告结束后，官方引擎返回 `1015` 视频载入错误。当前界面会让出视频内错误提示并提供重试，正片持续播放及完整观看流程尚未通过验收。
- 真实账号登录后的云端收藏、观看记录与播放进度，需要用户在官方登录页完成登录后验证。
- iOS 工程尚未在 macOS/Xcode 编译或运行。同一份 Dart 布局测试不能代替 iOS 设备验收。
- 正式 Android 签名、iOS 签名及发布流程留待完整功能验收完成。

本地截图、验收 JSON、工具链与测试 APK 位于忽略的 `artifacts/` 和 `.tools/` 目录，不提交账号会话或用户提供的参考图。
