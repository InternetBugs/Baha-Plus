# 本地验收

当前为 Flutter 迁移与播放页重写的开发版本。Android 在本地构建；没有触发 GitHub Actions 或正式发布。

## 已验证

- `flutter analyze --no-pub` 无问题。
- 35 项 Dart 核心及界面测试通过：包括系统代理和直连网络、账号资料、自动更新、云端记录、搜索异步隔离与账号网络通道、公开主视图缓存、首页轮播、两种新番视图、嵌套播放跳转、片库瀑布流、五个底栏二次点击回顶、过渡动画中的页面状态保留，以及既有播放器行为。
- 20 项官网适配器测试通过：包括时间线日期跨年解析、目录、详情、账号资料、收藏、观看记录分页与去重、无断点记录、接口错误与空结果区分、账号身份一致性、播放器命令限制及错误处理。
- `npm run resources:check` 验证 144 项双语资源；`npm run typecheck` 通过。
- 本地 x86_64 Android debug 及 release 模式测试 APK 已编译、覆盖安装并运行于 API 35 专用模拟器。release 体验中保留官方登录，观看记录自动显示，手动同步入口已移除。
- 实际官网目录与详情读取；搜索输入及清除、语言与外观设置、时间表、片库和账号面板。
- 断网无目录缓存时首页留白；恢复真实缓存后可冷启动显示；失败刷新保留缓存；联网后可刷新。
- 人气片单改为随首页纵向滚动的瀑布流，按内容自然错列并逐项构建，可继续滚动到原横向列表截断数量之外。目录缓存状态行已移除，缓存行为保留。
- 播放页由 Flutter 绘制导航、圆角视频区域、选集、简介及作品资料。
- 视频内玻璃控制条替代原控制栏；没有视频外的独立控制面板。
- 实际广告视频的播放、暂停、静音与时间进度已通过新控件验证。广告期间拖动、快进、倍速与画质命令被阻止。
- 在用户授权测试中点击官方年龄确认后，新会话正常完成广告并进入正片，正片接口返回成功，视频连续播放时间已推进到三分钟以上。
- 真实正片已验证十秒快进/后退、进度拖动、1.5 倍速、静音、官方提供的 360p 画质选择及弹幕显示开关。先前游客验收时仅提供一个画质档位，多档位及会员画质尚需进一步验证。
- 真实正片切入后台后立即暂停；返回前台保持暂停，用户可继续播放。后台加载完成的新文档也保持媒体暂停约束。
- 横屏和竖屏切换保持同一个官方视频文档及当前请求标识。
- 官方账号入口进入巴哈姆特登录页。年龄提示保留在视频区域，测试中的确认点击已获用户明确授权。
- 官方资料读取、账号卡片与首页头像显示，以及覆盖安装并冷启动后的登录会话恢复与资料重读，均已在 Android 模拟器核对。公开记录只保留功能验证结论。
- 官网观看记录由接口异步生成，不能从初始 HTML 的空容器判断为空。已接入官网实际使用的分页接口，并在真实登录会话中核对作品、集数与进度；公开文档不保存账号内容或数量。
- 账号面板移除重复的快捷区及手动同步入口；观看记录成为独立底栏页面，登录后、回到前台、进入记录页及关闭播放页自动更新账号资料。系统要求减少动画时跳过页面位移动画。
- 验收模拟器此前将系统动画倍率设为 0，已恢复为正常 1 倍，供实际检查底栏选中项与页面切换动画。
- 真实联机检查确认公开搜索与主视图数据可通过官网会话网络通道取得；直接 Dart HTTP 曾出现 TLS 握手失败，现已改用现有官方 WebView 的异步 JSON 请求，未关闭证书校验。
- 主视图与每集缩略图分别保留：片库和顶部轮播使用主视图，首页新番时间线使用每集横屏缩略图。公开海报元数据独立补全并保留于目录缓存。
- `integration_test/catalog_smoke_test.dart` 在真实 Android 模拟器联机通过：简繁关键词搜索直接显示结果、番剧主视图与剧集图分离、片库瀑布流、顶部轮播左右滑动，以及首页独立新番时间线入口；实际等待片库主视图、轮播与剧集缩略图完成解码。
- 修复图片网络未读取设备系统代理而一直显示占位图的问题；封面缓存和头像共用系统代理感知的 HTTP 客户端，正常保留证书校验。离线测试分别验证代理与无代理直连，联机测试覆盖真实 CDN 图片。
- 2026-11-07 本地构建 `0.2.1+3` 普通 `lib/main.dart` 入口的 release APK，同时包含 ARM64 与 x86_64 Flutter 引擎，APK 签名校验通过。覆盖安装后在游客会话实查首页主视图轮播、片库竖版瀑布流和按日期排列的横屏剧集时间线，图片均正常显示；手机账号体验由用户自行登录。

## 性能检查

- 已启用玻璃质量自适应，最低保留标准玻璃效果；限制图片解码宽度，普通数据变化不再重建整个应用主题。
- 同一 Android 模拟器、debug 构建及六次固定首页滑动脚本中，优化前绘制耗时中位数约 20.9 ms，优化后热身复测约 11.1 ms。优化后首次加载仍出现较长帧，热身复测 P95 约 22.7 ms，尚未达到所有帧均在 16.7 ms 内的目标。
- 这些观测来自 debug 模拟器，不能作为真机或正式构建的性能结论。本地 release 模式使用测试签名供体验，不代表正式发布。
- 本轮观看记录控件调试中，独立模糊层曾带来额外绘制开销；进度轨道改为轻量高光绘制，播放按钮保留玻璃组件。固定滑动脚本的调试观测中位数约 21.5 ms、P95 约 30.8 ms，样本有限，仍有长帧。
