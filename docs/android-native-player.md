# Android 原生播放迁移

本实验在 `codex/android-native-player` 分支进行，起点为 `ff7c339376cc4352056602e681425a4640262706`。主分支不合入本次迁移；该 Android 分支的实测不覆盖 iOS。后续 iOS 适配在 `codex/ios-native-player` 独立分支继续，见 [iOS 原生播放迁移](ios-native-player.md)。

## 播放路径

官方页面仍先完成年龄确认、广告、会员、地区和设备校验。页面确认当前集进入正片、取得可播放时间线后，Android 才准备原生播放器。播放源只接受本次官方会话给出的 `bahamut.akamaized.net` HTTPS HLS 地址，画质只接受该清单真实列出的档位。

Android 使用 Flutter 官方 `video_player` 的 ExoPlayer 后端和纹理画面。保存的画质用于原生播放器的第一个媒体源；手动切换和自动模式继续使用本次已授权清单，保留位置、倍速、静音和暂停意图。接管前最后一次读取网页实际进度，避免原生初始化期间页面继续播放造成进度回跳。

官网进入正片后先暂停 HTML 视频并保留接管前的播放意图，原生初始化成功后卸载 HTML 视频、停止 VHS、网页弹幕动画及 Media Session，再开始原生播放。2026-11-09 在共享播放代码中取消了原生初始化失败时的静默网页回退：失败显示重新加载入口，重新经过官方流程；准备期间的网页正片控制同样被拒绝。切集、刷新和退出会释放旧控制器和纹理。

原生接管后将官方 WebView 放入 `Offstage`，保持挂载和原有布局，但不再把已被遮住的网页纹理加入 Flutter 画面合成；官方会话、权限检查和心跳继续运行。退出原生播放后恢复网页绘制。

本实验保留一个精简的官方 WebView 会话，不是完全移除全应用的 WebView。重的页面内容和 iframe 被移除；真实账号、剧集标记及官方错误显示容器保留。官方 player 的时间、暂停等读取接口接收原生播放器的实际状态，原有观看时长、设备锁和进度回传回调继续运行。账号或设备政策拒绝时停止原生播放。Cookie、CSRF 和设备标识不导出到 Flutter、日志或偏好。

## 弹幕和生命周期

弹幕数据从当前官方会话投影为纯文本、时间、模式、颜色和字号，由 Flutter 的单个绘制层显示。最多保留 64 个活动文字绘制对象；离场、关闭弹幕和退出时销毁。数据投影上限为 20,000 条，Flutter 确认接收后释放对应的网页数据副本，后续新增弹幕按 ID 合并。

支持原有透明度、字号、滚动、顶部和底部设置。发送仍走官方页面的账号、CSRF 和权限校验，发送时间采用实际原生播放进度。测试不向官方发布弹幕或留言。

隐藏或后台时暂停，返回前台保持暂停。切画质期间经过后台往返会锁定暂停意图，异步完成不能自动重新播放。Android 系统媒体会话的播放、暂停和定位命令绑定当前文档，转交现有 Flutter 控制入口；退出或更换文档后旧命令失效。屏幕常亮沿用现有实际播放状态。

2026-11-13 起，Android 与 iOS 共用前台续播恢复：后台往返后点击播放先使用原会话及有效缓冲，失效时从当前剧集、进度、倍速、静音及已保存画质重建。首次尝试后最多额外重试两次，整轮技术恢复最多 30 秒；期间沿用正常加载转圈及已有网速显示，失败后才显示手动重试。恢复成功直接执行本次播放请求；恢复途中切后台、退出或切集会取消恢复并拒绝迟到结果。官方广告及验证走原流程，明确拒绝不自动重试。整个 App 被系统回收后的处理沿用原逻辑。

Android 没有额外的系统后台分片预取任务；原生媒体缓冲仍由 ExoPlayer 管理。前台手动暂停保留其正常缓冲行为，后台暂停保留播放器和仍有效的缓冲。当前插件没有单独冻结所有在途媒体请求的接口，因此不能把后台暂停描述为底层网络立即归零。iOS 回退播放的缓存网关暂停机制不引入 Android。

前台正片遭遇渲染进程退出、可恢复的解码错误或连续 30 秒进度不推进时，保存当前剧集、进度、倍速和静音，释放旧原生控制器后重新经过官方播放流程；恢复时继续使用保存的画质。Android 渲染进程退出会重建 WebView，旧实例的消息和退出回调不能干扰新会话。30 分钟内最多自动恢复两次，恢复加载逾时或次数耗尽后显示手动重试。原本暂停、处于后台、广告及明确的官方拒绝不会自动播放。

弹幕动画按引擎的同一帧时间推进，重复播放状态通知不重置动画时间；小幅原生时间误差渐进校准，定位跳转立即生效。每条可见弹幕保持已分配行位，旧弹幕离场不会使其他弹幕重新排队。被密度限制跳过的弹幕也不会在行位空出后突然出现在半程。对应时钟和行位回归在 `app/test/danmaku_animation_test.dart`；诊断包额外记录 Flutter 绘制帧统计，它与视频解码丢帧计数是不同口径。

活动弹幕的文字和阴影按设备像素比例栅格化一次，运动时复用图像；离场、关闭弹幕或修改样式后释放。图像缓存按保守的每像素 8 字节估算，上限 16 MiB，同时限制单张图像尺寸。超预算或超长文字走普通文字绘制路径，不为缓存放宽内存边界。

## 本地验证

接管与授权边界的离线测试位于 `tests/native-playback.test.ts`（Android 分支原名 `tests/android-playback.test.ts`）；原生画质、资源释放、后台切源和弹幕绘制对象上限位于 `app/test/native_playback_test.dart`。

真实 Android 模拟器测试入口：

```powershell
flutter test integration_test/native_player_smoke_test.dart `
  -d <现有模拟器ID> --no-uninstall `
  --dart-define=BAHA_DIAGNOSTICS=true
```

该测试选择官方的“同意”年龄按钮，等待官方广告和授权，确认真实 ExoPlayer 纹理及网页媒体源卸载，验证画质、暂停、定位、全屏和生命周期，再连续播放十分钟并退出。年龄确认仅在该测试中操作，不在产品中自动选择。保留 `--no-uninstall`，避免清除模拟器登录与偏好。

普通主入口安装包另行验证 Android 实际桌面往返和系统媒体命令；不要在连续播放的 Flutter 集成测试中插入外部点击，测试框架会截获这些设备事件。原始日志、内存采样和截图保留在本地忽略的 `artifacts/android-native-player/`。

## 对照和回退

本分支默认在 Android 启用原生正片，可用编译参数关闭，便于对照：

```powershell
flutter build apk --debug --dart-define=BAHA_ANDROID_NATIVE=false
```

关闭后仍走原有官方网页播放路径。也可在保存迁移分支提交后切回 `main`。不修改账号会话，不卸载应用，不创建版本标签或正式发布。
